# HDR Photo Viewer

Нативный просмотрщик фотографий для **macOS 15+ и Apple Silicon (M1 и новее)**.

## Установка

1. Откройте [Releases](https://github.com/Arthuralend/Viewer/releases) и скачайте `HDR.Photo.Viewer.dmg` из последней успешной сборки.
2. Откройте DMG и перетащите **HDR Photo Viewer** в **Программы**.
3. Запустите приложение и выберите фотографию или папку.

Предварительные сборки имеют локальную ad-hoc подпись, без Developer ID и нотариализации Apple. При блокировке первого запуска попробуйте открыть приложение, затем разрешите запуск через **Системные настройки → Конфиденциальность и безопасность → Открыть всё равно**, если macOS предлагает эту кнопку.

## Возможности

- Встроенный проводник папок с миниатюрами, историей, переходом вверх и строкой пути.
- Выбор фото открывает его папку и позволяет просматривать соседние снимки.
- Листание ←/→ в окне и на полном экране; естественная сортировка имён.
- HDR/SDR переключатель, учёт EXIF orientation и цветовых профилей.
- Core Image HDR decoding и Metal EDR с float-буфером и адаптацией к диапазону экрана.
- Исходные фотографии не изменяются; приложение не отправляет их в сеть.

| Клавиша | Действие |
|---|---|
| ⌘O | Открыть фото |
| ⇧⌘O | Открыть папку |
| ← / → | Предыдущее / следующее фото |
| F или Control–Command–F | Полный экран |
| Esc | Выход из полного экрана |
| ⌘B | Показать / скрыть проводник |

Папка открывается двойным щелчком. Двойной щелчок по миниатюре включает полный экран.

## Сборка

Нужны Xcode 16+ либо Command Line Tools с macOS 15+ SDK.

```bash
bash build.command
bash package-dmg.command
```

Приложение: `build/HDR Photo Viewer.app`. Установочный образ: `build/HDR Photo Viewer.dmg`.

GitHub Actions собирает arm64-приложение при изменении `main`, запускает проверки декодирования JPEG/EXIF, обработки повреждённого файла, float HDR, SDR tone mapping и фильтра форматов, проверяет подпись и DMG, затем публикует предварительный релиз с контрольной суммой SHA-256. Повторную сборку можно запустить вручную в [Actions](https://github.com/Arthuralend/Viewer/actions).

## Ограничения

Это предварительная версия. Автоматические проверки не подтверждают визуальное совпадение с Photos или Camera Raw. Проверка реальных iPhone HDR-файлов на экране остаётся необходимой.

Поддержка Apple gain maps и Adaptive HDR зависит от системного декодера. Не все варианты JPEG Adobe/Ultra HDR гарантированно поддерживаются. Для неизвестного HDR headroom и SDR-экрана используется SDR-представление. RAW/ProRAW DNG пока не поддерживаются. Масштаб 1:1 и панорамирование пока отсутствуют.

Пиковая яркость MacBook Air M1 и доступный EDR headroom ограничивают сходство с яркими HDR-экранами iPhone.

Подробности API и план визуального тестирования: [HDR notes](docs/HDR-notes.md).
